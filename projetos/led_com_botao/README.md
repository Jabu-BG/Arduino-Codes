# 🤖 Estudos com Arduino

Repositório dedicado aos meus estudos de eletrônica e programação de microcontroladores com Arduino.

## 🔌 Projetos

### LED com Botão

Projeto que utiliza uma entrada digital para identificar o acionamento de um botão e controlar um LED.

**Funcionamento:** quando a entrada do botão está em nível HIGH, o LED alterna entre ligado e desligado, com intervalos de 100 milissegundos.

**Configuração do código:**
- Pino digital 10: entrada do botão
- Pino digital 9: saída do LED

## 🛠️ Ferramentas

- Arduino IDE
- Linguagem C/C++ para Arduino

## ▶️ Como executar

1. Abra a Arduino IDE.
2. Abra `projetos/led_com_botao/led_com_botao.ino`.
3. Conecte sua placa Arduino.
4. Confira as conexões do circuito.
5. Selecione a placa e a porta corretas.
6. Compile e envie o programa.

## 🎯 Objetivos de Aprendizagem

- Leitura de entradas digitais
- Controle de saídas digitais
- Estruturas condicionais
- Temporização com `delay()`
